# Vyoro QA Case Study

Vyoro is a portfolio-based hiring platform that connects students, universities and companies. I tested the student portal as a QA member and also contributed UI/UX design in Figma.

## Results
- 13+ bugs documented, including a critical submission failure (now fixed)
- UI test cases written for registration, including boundary and negative cases
- Redesigned a project-submission flow that bypassed company review
- Defects tracked in Jira through retest

## What is in this repo
- [Bug reports](bug-reports): the most important bugs written
- [Test cases](test-cases/registration-test-cases.md): sample registration test cases
- [Workflow redesign](flow-redesign/submission-flow.md): the project-submission fix


## How I test
I plan the test cases, run them manually, report each defect with exact steps to reproduce, retest after the fix, and run a short regression pass before closing.
