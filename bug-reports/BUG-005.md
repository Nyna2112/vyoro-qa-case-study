# BUG-005: No way to reset password from student sign in page (negative path)

| Field | Detail |
|---|---|
| Severity | High |
| Priority | High |
| Status | Closed / Verified |
| Environment | A student account is created to test the flow |
| Found by | Neyna Gunti |


## Requirement analysis
Students need a way to reset their password if they forgot it.

## Test planning
Testing whether there is a way for the users to reset their password by functional testing, exploratory testing, black box testing, manual testing by entering the wrong password in the student sign in page and checking for a way to reset the password.

## Scenario
Reset password link – student portal

## Steps to reproduce
Precondition: Student needs to have an account either via university email method or recent graduate method

1. Launch student portal
2. Click on Sign in
3. Enter email
4. Enter wrong password
5. Click on Sign in

## Expected result
Should have a link to reset the password.

## Actual result
No option found to reset.

## Severity and priority
- Severity: High because if there is no option to reset the password the students might never get access to the portal which breaks the students sign in flow.
- Priority: High, it needs to be resolved first as it is stopping the users from completing a necessary action to access their portal.

## Test execution
Found the bug by logging in student portal by entering wrong password on purpose.

## Test closure
- Reported the bug to the developer 
- Retested the flow to check whether it's in progress / fixed
- Changed the status to Closed / verified once it's done
