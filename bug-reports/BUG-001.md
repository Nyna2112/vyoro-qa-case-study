# BUG-001: No submit button found to Submit Project deliverables on the track applications page when the progress is at 100%

| Field | Detail |
|---|---|
| Severity | High |
| Priority | High |
| Status | Verified / Closed |
| Environment | Few student, company accounts were created to test the flow, chrome browser, hp laptop device |
| Found by | Neyna Gunti |


## Requirement analysis
Students should have to submit their completed project work to have their work visible in the portfolio if their work is successfully accepted by the company.

## Test planning
Testing if there is a way to submit the project after completion through student portal by exploratory, functional, blackbox, manual testing.

## Scenario
Submission flow – student portal

## Steps to reproduce
Precondition: Student should already have an account and got accepted for a project and being ready for submission i.e. the progress should be at 100%

1. Launch the student portal, click on Login
2. Enter test data credentials and login
3. Go to the track applications tab
4. Click on the accepted project
5. Check whether it has a submit project option or not when the progress of the project is 100%

Test data: Student test account (shared separately). Project: Menu data validation project from test company.

## Expected result
Should have a button to Submit the project.

## Actual result
No option found to submit the project.

## Severity and priority
- Severity: High because if there is no option to submit the project it may not be entered in to their portfolio, which breaks the flow of automatically adding verified projects in to students portfolio.
- Priority: High, it needs to be resolved because it won't let the tester test further features if it breaks.

## Test execution
Found the bug by logging in student portal and checking the track applications sections after the student got accepted for that project and ready to submit it.

## Test closure
- Reported the bug to the developer
- Retested the flow to check whether its pending or closed
- Changed the status to verified/closed once its done
