# BUG-003: Missing functionality to view project details

| Field | Detail |
|---|---|
| Severity | High |
| Priority | Medium |
| Status | Fixed |
| Environment | A few student and company accounts were created to test the flow and accepted the student application via company's account to test whether it shows the details or not |
| Found by | Neyna Gunti |


## Requirement analysis
The users need to view the project details to start the project once they are accepted for that project.

## Test planning
Testing needs to be done on the functionality of the project details feature by functional testing, manual testing, exploratory testing, black-box testing, usability testing because that option is a must have, without that the users cannot start the project and they may feel confused.

## Scenario
No option to view project details – student portal

## Steps to reproduce
Precondition: Student application must be accepted by the company

1. Go to student portal
2. Go to login page
3. Login via a student account
4. Go to projects section
5. Apply for a project
6. Go to track applications
7. Click on the applied project
8. Search for project details

## Expected result
Able to view project details through a button or drop down item.

## Actual result
No option to view details.

## Severity and priority
- Severity: High because users cannot start a project until they know the details of it.
- Priority: Medium, because students could get details by messaging the company, but it shouldn't stay that way.

## Test execution
Found the bug while testing the entire flow from application to completion of the project.

## Test closure
- Reported it to the developer
- Retested the feature to check whether it shows the details or not
- Changed the status to fixed once confirmed
