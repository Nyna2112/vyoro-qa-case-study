# BUG-006: Wrong 'Stage verified, Next stage unlocked' message shown at 100% progress

| Field | Detail |
|---|---|
| Severity | Low |
| Priority | Low |
| Status | Open (retest pending until a fix is in) |
| Environment | A student account and a company account were created to test the flow |
| Found by | Neyna Gunti |


## Requirement analysis
Student progress unlocks stage by stage (25/50/75/100%). At 100% there is no next stage, so the next step is submitting deliverables.

## Test planning
Testing the reviewer feedback instruction when the progress of the project shows 100% by manual testing, exploratory testing, blackbox testing, functional testing.

## Scenario
Reviewer feedback option not needed for a completed project – student portal

## Steps to reproduce
Precondition: Student needs to have an account, and must be accepted for a project and be ready for submission of the project i.e. the progress should be 100%

1. Go to the student portal
2. Login via a student account
3. Go to track applications page
4. Click on the accepted project at 100% progress
5. Look at the reviewer feedback section on the project page

## Expected result
Option not needed: "Reviewer feedback option not needed at this stage"

## Actual result
Option found with a wrong instruction being displayed: "Stage verified, Next stage unlocked"

## Severity and priority
- Severity: Low because it doesn't stop the user from submitting the project.
- Priority: Low, it's a misleading message that doesn't block submission, so it can be scheduled in a normal sprint.

## Test execution
Found the bug by logging in student portal by checking the post acceptance flow.

## Test closure
Reported the bug to the developer with status as Open.
